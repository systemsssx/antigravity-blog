## 技术说明

- **单文件**：全部 CSS / JavaScript 内联，不引用任何外部字体、图片或 CDN，断网也能正常阅读。
- **主题**：页面右上角可切换亮色 / 暗色主题，选择会记录在本地浏览器中。
- **编码**：UTF-8（无 BOM），适配桌面与移动端。
- **部署**：根目录的 `index.html` 可直接作为 GitHub Pages 首页；`.nojekyll` 用于跳过 Jekyll 处理。
